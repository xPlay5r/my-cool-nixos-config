# my-cool-nixos-config
Этот гитхаб репозиторий содержит мои dotfilы. Но не все. Некоторые конфиги все еще не обьявлены тут. Здесь вы можете найти некоторую полезную информацию, по тому, как настраивать свою систему. В последние дни разбил систему на модули, так что теперь у меня триллион всяких файлов. При разделении файлов я следовал такой логике:

1. flake.nix

Начало всей конфигурации. outputs обернут в flake-parts.lib.mkFlake, этот фреймворк подставляет целевую систему в нескольких местах. Все привычные опции outputs теперь лежат внутри flake = { ... } внутри flake-parts.lib.mkFlake.

2. flake.nix -- nixosConfigurations.vlad

Конфигурация для пользователя vlad. vlad внутри nixosConfigurations -- это что-то типа профиля. Только сейчас я выбираю какие модули подключать, для какого компьютера этот профиль, какого юзера на этом компьютере я создам

3. ./hosts/nixos/ , ./users/vlad/

Во flake.nix я импортирую их, эти файлы отвечают за базовые опции отдельно для машины и пользователя, а также импортирую нужные модули, или пишу опции, которые нельзя собрать в отдельный модуль.

4. ./modules/*

Здесь я определяю модули -- home-manager/nix код, разделенный на файлы по отдельным задачам.

## Не нужно пытаться прочитать мой код как стих
Не пытайтесь запомнить за что отвечает отдельные файлы, обобщайте так: "Здесь должно описываться приложение X, а здесь должно описываться какие приложения установятся для хоста B". Я разделял файлы по своей логике так, чтобы было проще работать *мне*, а не читающему

## Как написать подобный конфиг?
nix документация нечитаема. Я до сих пор не понимаю первые главы официальной документации. У вас не будет единого источника всей нужной информации

Сначала советую прочитать nix language, запомнить как можно больше: https://nix.dev/tutorials/nix-language#names-values

Первое время ничего не будет понятно. Смотрите сразу на готовые конфиги и ищите обьяснение каждой строке, хоть это будет очень неприятно: https://nixos-and-flakes.thiscute.world/nixos-with-flakes/get-started-with-nixos (не уходите сразу в дебри, найдите простое обьяснение)

Пытайтесь искать паттерны самостоятельно. Поищите быстрые старты с nixos. https://github.com/Misterio77/nix-starter-configs/tree/main

Знание configuration.nix уже достаточно, чтобы настроить работающую систему, но мы хотим обьявить конфигурацию для абсолютно всего, даже .config. После configuration.nix узнайте про flake.nix и home-manager. Не углубляйтесь во все опции, узнайте про inputs и outputs во flake.nix. К этому моменту вы, наверное, уже знаете про man-страницы configuration.nix(5) и home-configuration.nix(5). Там описываются опции для всех доступных программ.
