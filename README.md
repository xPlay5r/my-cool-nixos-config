## Как повторить мой конфиг
Я бы не советовал копировать, но я опишу то, как я бы скачал свой конфиг на новую систему.
1. Сделайте установку nix через live iso
2. Загрузитесь с системы, переместите содержимое /etc/nixos/ в любую папку из домашней директории. Я переместил в ~/nix/
3. Создайте симлинк /etc/nixos/configuration.nix -> ~/nix/configuration.nix (измените на выбранную директорию)
4. Напишите в ~/nix/configuration.nix `nix.settings.experimental-features = [ "nix-command" "flakes" ];` внутри `{}: { __тут__ }`
5. Пересоберите систему. Теперь доступны команды `nix ___ [...]`, а также flake операции. Теперь nixos ищет не /etc/nixos/configuration.nix, а /etc/nixos/flake.nix
6. Теперь вы можете копировать мой репозиторий в ~/nix/.
> [!CAUTION]
> совмещайте мои опции с автоматически сгенерированными аккуратно! Если вы поменяете `system.stateVersion`, то система не обновится, а сломается: будете сидеть на полусломанной системе, негативные эффекты будут накаливаться со временем.
8. Удалите /etc/nixos/configuration.nix (`rm` не удалит файл, на который симлинк указывает)
9. Создайте симлинк /etc/nixos/flake.nix -> ~/nix/flake.nix
